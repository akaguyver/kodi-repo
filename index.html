Sortovia

A free add-on for Kodi that turns a pile of downloads into the folders Kodi understands. You see the whole plan first, and nothing moves until you say so.

E:\
├── TV\Show Name (Year)\Season 01\Show Name (Year) S01E02.mkv
├── Movies\Movie Name (Year)\Movie Name (Year).mkv
├── Comics\Series\<original file>.cbz
└── Tutorials\AutoCAD\<original file>.mp4

Install it in Kodi

  1. Go to Settings → System → Add-ons and turn on Unknown sources. Choose Yes at the warning.
  2. Go to Settings → File manager → Add source. Select the box that says <None>, type https://akaguyver.github.io/kodi-repo/, and name it kodirepo.
  3. Go to Settings → Add-ons → Install from zip file → kodirepo and pick script.kodisorter-1.39.1.zip.
  4. Recommended, for .rar and .7z files: Install from repository → Kodi Add-on repository → VFS add-ons → Archive support.
  5. Open Sortovia from Add-ons → Program add-ons and follow the welcome screen.

What you need

  • Kodi 19 or newer, and your files on a drive Kodi can see.
  • Nothing else. An Android phone, a free TMDb key and Real-Debrid are optional extras.

Built and tested on Kodi 21 on an Xbox One S. Other devices should work but haven't been tested yet, so try it on a few files first. Sortovia moves and deletes files when you approve it, so keep a backup of anything you can't replace. Free software under the MIT licence, with no warranty.
